# Changesets

Execute `pnpm changeset` para registrar os pacotes alterados, o tipo de versão (`patch`, `minor` ou `major`) e um resumo da mudança. Inclua o arquivo gerado no commit.

Cada pacote tem sua própria versão e changelog. Consulte o [fluxo de versionamento e publicação](../docs/packages.md#versões-e-publicação) para preparar um release.
